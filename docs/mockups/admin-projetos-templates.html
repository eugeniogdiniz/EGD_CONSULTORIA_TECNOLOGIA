Como cria projeto a partir de template

Quando você tem uma oportunidade Ganha e abre o botão Criar projeto, o diálogo ganha um dropdown de template. Se selecionado, fases e entregas do template são materializadas na mesma transação da criação.

Regras dos templates

Snapshot rígido. Editar o projeto original depois de virar template não muda o template. Sem herança viva.

Sem conteúdo. Templates carregam só a estrutura: fases (nome, ordem, notas) e entregas (título, descrição, ordem). Sem prazo, sem status, sem anexo, sem responsável.

Nome único. A tabela tem unique(name). Duplicidade cai em fail claro na criação.

Deletar template não afeta os projetos já criados — o snapshot foi para o projeto no momento da materialização.
