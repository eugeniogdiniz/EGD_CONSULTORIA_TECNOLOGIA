Regras

  • Cabeçalho não é link. Fragment Mono 13 px, `--fg-muted`, chevron 12 px à direita. `role="button"`, `aria-expanded`, `aria-controls`.
  • Sub-item ativo força aberto. Se a URL bate com prefixo de qualquer sub-item, o grupo abre e ignora o estado persistido enquanto a navegação estiver ali.
  • Persistência em `localStorage`, chave `egd_admin_nav`, JSON `{ groups: { crm: "open" | "closed" } }`.
  • Sem animação de altura. Toggle instantâneo. O chevron gira em 160 ms (só rotação, não altera layout).
  • Aninhar é proibido. Um nível só. Sub-item de sub-item não existe.
  • Selo `.badge` continua permitido à direita de qualquer sub-item (mesmo padrão de `Leads`).

Interativo

clique no cabeçalho "CRM" da sidebar principal (topo) para ver o toggle real

A sidebar principal desta página (à esquerda) exercita o padrão: cabeçalho "CRM" clicável, chevron gira, sub-itens somem sem animar altura. O sub-item ativo (Funil) reabre o grupo se você tentar fechar enquanto está nele — para simular, mude o `aria-current` no HTML ou navegue.
