Regras da visão geral

Fases e marcos aparecem sempre. Entregas só aparecem quando a equipe marca como visível ao cliente; contadores das fases consideram só essas.

"Bloqueada" vira "Em espera". O motivo interno do bloqueio nunca é exibido.

Sem valores. Orçamento, horas, custos, dependências e propostas ficam de fora.

Marco atrasado = data passada e não concluído (data em vermelho).

Acesso indevido. Abrir o link de um projeto de outra organização devolve 404, igual a um projeto inexistente.
