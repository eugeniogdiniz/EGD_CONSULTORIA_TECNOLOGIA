Casos de borda

Oportunidade sem estágio Ganho — o botão "Criar projeto" nem aparece; a ação recusa se chamada direto (mensagem "Só oportunidades ganhas viram projeto.").

Oportunidade que já tem projeto — o bloco no detalhe da oportunidade vira "Projeto associado" com link direto; sem botão de criar. Segunda tentativa via corrida cai no unique constraint (23505) e vê a mesma mensagem.

Deletar oportunidade com projeto — o FK on delete restrict impede. A UI da Fase 2 não oferece deletar oportunidade; se um dia oferecer, precisa checar antes.
