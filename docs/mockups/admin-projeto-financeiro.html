Fórmulas

labor = Σ floor(entrada.minutes × rate.hourly_cents ÷ 60) só das entradas fechadas com rate presente.

cost = labor + expenses.

revenueAccepted = Σ crm_proposal.valueCents onde status = 'accepted'.

margin = revenueAccepted − cost.

marginPct = arredonda margin ÷ revenueAccepted × 100 (0 se receita = 0, evita div/0).
