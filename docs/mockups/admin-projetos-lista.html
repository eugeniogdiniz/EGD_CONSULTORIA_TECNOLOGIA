Por que não tem botão "Novo projeto"?

Projeto nasce a partir de uma oportunidade ganha no CRM. No detalhe da oportunidade, quando o estágio é "Ganho" e ainda não há projeto, aparece o botão Criar projeto; se já existe, vira Ver projeto. Isso preserva a rastreabilidade funil → execução e evita projetos avulsos sem origem comercial. Se precisar de projeto interno (sem cliente), crie oportunidade "interna", marque como ganha e crie o projeto a partir dela.
