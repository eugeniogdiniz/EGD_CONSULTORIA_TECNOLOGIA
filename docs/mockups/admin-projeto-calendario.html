Regras do calendário

Somente com data. Só marcos e entregas que têm due_at aparecem. Sem data, ficam invisíveis no calendário (aparecem no kanban ou no detalhe).

Chip pontilhado = marco. Chip liso = entrega. Cor do pip = status.

Cinza claro = dia de outro mês, incluído pra manter grid 6×7 estável.

Navegação. URL guarda ?ym=YYYY-MM. Botão "Hoje" volta pro mês atual do server (UTC).
