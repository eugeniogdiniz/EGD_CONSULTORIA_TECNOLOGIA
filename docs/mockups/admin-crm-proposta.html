Regras da transição de status

para o time saber por que um botão está desabilitado

Rascunho → Enviada exige arquivo anexado. Sem anexo, o botão fica desabilitado e a mensagem "Uma proposta enviada precisa ter arquivo anexado." aparece no campo Status. Ao marcar como enviada, o sistema pergunta a data (default hoje) e a validade (default 30 dias).

Enviada → Aceita / Rejeitada / Expirada abre um campo para "Notas de decisão" (opcional). A data de decisão é gravada automaticamente.

Expirada não roda automaticamente na Fase 2 — quem marca é o admin. Se valid_until passou e o status ainda é "Enviada", aparece um selo de aviso no cabeçalho.
